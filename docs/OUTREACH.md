# P3 demand engine — the playbook

The leaderboard is won by third-party USDC settled in an unannounced October
window. Everything here exists to create *recurring real payers* before
September ends. Zero self-generated volume, ever — /receipts is public and
must stay clean.

## Channels, in priority order

### 1. Fellow challenge entrants (highest conversion)
They are building agents on Algorand that need data/tools — we are the only
supply of the proven x402 economy there. Current Bazaar merchants to contact
(public list, via the facilitator discovery API): syraa.fun,
agent402.tools, compx.io (canix402 + amarok), netintel.dev, oyapicks.app,
algometrics.org, iomarkets.ai, secondopinionx402.com, civitasv.workers.dev.

Template:
> Building on the x402 challenge too — we just brought 50 verified Base
> services (LLM inference at $0.0006/call, token safety scans, market data)
> to Algorand through one gateway: {URL}. One line of code via the roam402
> SDK, pays in USDC on Algorand like everything else you're doing. If your
> agent needs a capability we don't wrap yet, tell us — we can add routes
> within a day. And every call you make counts as YOUR wallet's real usage
> too.

### 2. Algorand Foundation / GoPlausible amplification
The story writes their blog post for them: "Algorand's x402 catalog just
grew by 50 verified services." Ask for: a mention in the challenge updates,
a retweet, and (GoPlausible) a featured merchant slot. We give back: the
Agents-Trust observatory adds a public Algorand lane chart they can cite.

### 3. Origin sellers (co-marketing, defuses resale concerns)
Top wrapped sellers get a note: their API now earns on Algorand, zero work,
full price per call. Ask for a retweet/mention; offer opt-out. Contact
leads live in contact-discovery (private) — never commit contact data here.

### 4. SDK distribution
- Publish `roam402` to npm once mainnet is live (sdk/ is ready).
- Example PRs/snippets to Algorand agent-skills repos and x402 awesome-lists.
- examples/agent-call.ts is the demo: precheck → trust → paid LLM call.

## Cadence

- Week of Aug 11: origin-seller notes to top 10 wrapped services.
- Ongoing: every new Bazaar merchant gets the entrant DM within 48h.
- September: submission + a public "receipts so far" thread.
